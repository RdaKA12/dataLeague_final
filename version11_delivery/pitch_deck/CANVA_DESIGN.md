## PPTX export

The Canva connector created the editable design, but this session does not expose
a direct Canva PPTX export tool. Export from the Canva UI:

1. Open the edit URL.
2. Click `Share`.
3. Click `Download`.
4. Select `Microsoft PowerPoint (.pptx)`.
5. Download all pages.

This Canva version should be used as the final visual pitch deck instead of the
locally generated draft PPTX.
