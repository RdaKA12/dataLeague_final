# V11 Pitch Deck

Build the final presentation from V11 metrics and analytics:

```powershell
python version11_delivery\pitch_deck\build_v11_pitch_deck.py
```

Outputs:

```text
version11_delivery/pitch_deck/dataleague_v11_final_pitch_deck.pptx
version11_delivery/pitch_deck/V11_SLIDE_FLOW.md
```

- Reliability / organicity scoring algorithm
- Manipulation map dashboard
- Live inference pipeline
- Dashboard and presentation rubric
